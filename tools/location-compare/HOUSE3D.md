# 여기살까? — 3D 집(R3F) 기획안

2026-10-14 초안. **방법 A: 코드로 도형을 조합해 집을 만든다**(사진 → 3D 변환은 다음 단계, 9절).
목표는 두 가지 — ① 교통평점 카드의 집 그림을 실제로 돌려 볼 수 있는 3D로 바꾸고, ② 그 과정에서 R3F를 익힌다.

> 표시 ☐ = 아직 정하지 않음(사용자 결정). 정하면 ☑ 로 바꾸고 내용을 적는다.

---

## 1. 지금 상태 (출발점)

- 교통평점 카드 가운데(`TransportCard.tsx` `House3D`)에 **아이소메트릭 SVG 집**이 있다 — 146×134px, 지름 184px 원(종합 점수 호) 안, 지붕 색 = 순위(1위 `#3f9a62` → 2위 `#5e8f9e` → 3위 `#8a7fa8` → 4위 이하 `#a08868`).
- 벽 = 따뜻한 회백색(`#f4f1ea` ~ `#c8c1b2`), 테두리 `#b9b2a3`, 문 `#6f5a43`, 창 `#cfe3ee`, 굴뚝 `#b9a58a`, 바닥 그림자 타원.
- 후보지 자료(`data.ts` `Candidate`)에 있는 것: 이름·주소·위경도·보증금/월세/관리비·**용도**(`use`: 주택 / 주거용 오피스텔 / 상가·기타). **층수·면적·향은 없다.**

## 2. 어디에 보여 줄지

| 단계 | 자리 | 내용 |
|---|---|---|
| 1차 | 교통평점 카드의 원 안(SVG 자리 그대로) | 같은 크기·같은 색으로 3D 집. 천천히 저절로 돈다(약 20초에 한 바퀴) |
| 2차 | 원(집)을 누르면 뜨는 큰 창 | 끌어서 돌리기·확대, 해 방향 표시(5절) |

- ☐ 2차 창을 지도 위에 띄울지, 화면 전체로 띄울지
- SVG 집은 지우지 않는다 → **3D를 불러오는 동안·WebGL이 안 되는 기기·"움직임 줄이기" 설정**일 때 그대로 보여 준다.

## 3. 무엇을 보여 줄지 (집 모양 규칙)

용도(`use`)마다 모양을 다르게 한다. 크기는 미터 단위로 생각하고 화면에 맞게 줄인다.

| 용도 | 모양 | 대략 크기(가로×깊이×높이) |
|---|---|---|
| 주택(`home`, 기본) | 박공지붕 단독주택 — 지금 SVG 와 같은 모습(벽 상자 + 삼각 지붕 + 문·창 2개 + 굴뚝) | 8 × 6 × 5 + 지붕 2.5 |
| 주거용 오피스텔(`officetel`) | 평지붕 직육면체, 층마다 가로 창 띠, 옥상 난간 | 8 × 8 × 15 (5층) |
| 상가·기타(`other`) | 낮은 상자 + 1층 통유리 + 차양 | 10 × 7 × 4 |

- 지붕(오피스텔·상가는 옥상 테두리/차양) 색 = 순위 색(1절, SVG 와 같은 값).
- 바닥: 둥근 잔디 판(옅은 초록 회색) + 부드러운 그림자.
- ☐ 순위 1위에만 작은 장식(나무 한 그루 등)을 둘지

## 4. 조작

| 상황 | 동작 |
|---|---|
| 카드 안(1차) | 저절로 천천히 회전. 마우스를 올리면 살짝 멈칫(속도 ↓). **끌기는 막는다** — 카드는 좌우로 끌면 후보지가 넘어가므로(UI-UX 3-1 Swipe) 겹치면 안 된다 |
| 큰 창(2차) | 끌어서 돌리기(`OrbitControls`), 휠/두 손가락으로 확대(범위 제한), 위에서 내려다보는 각도까지만(땅 밑으로 못 가게) |
| 후보지를 넘길 때 | 모양·지붕 색이 바뀌면 0.3초 동안 부드럽게(크기 줄었다 커지기) |
| "움직임 줄이기"(`prefers-reduced-motion`) | 회전 없음, 고정 각도 |

## 5. 해 방향 (2차, 배우기 좋은 덤)

- 후보지 위경도 + 지금 날짜·시각으로 해의 높이·방위를 계산해 조명(`directionalLight`)을 그 방향에 둔다 → 그림자가 실제 해 방향으로 진다.
- 창 아래 시각 막대(6시~20시)를 움직이면 해가 돈다. 집은 정남을 바라본다고 가정(향 자료가 없으므로 "가정" 꼬리표를 단다).
- ☐ 할지 말지 / 계절(동지·하지) 단추도 둘지

## 6. 분위기 (톤앤매너)

- UI-UX.md 1절의 밝은 테마를 따른다: 배경 투명(카드 흰색이 비치게), 장난감 같은 **로우폴리·무광** 재질(`meshStandardMaterial`, roughness 0.8 안팎), 테두리 선은 없음.
- 조명: 은은한 전체광 + 해 한 개 + 부드러운 그림자. 지나친 반사·네온·후처리 효과(블룸 등)는 쓰지 않는다 — 카드의 점수와 막대가 주인공이다.
- 카메라: 1차는 SVG 와 비슷한 아이소메트릭 느낌(약간 위에서, 왼쪽 앞).

## 7. 기술 구성

| 패키지 | 버전 | 쓰임 |
|---|---|---|
| `three` | 최신 | 3D 엔진 |
| `@react-three/fiber` | **8.x** | Three.js를 React 컴포넌트로(`<Canvas>`, `<mesh>`) — v9 는 React 19 필요, 여기는 React 18 |
| `@react-three/drei` | **9.x** | `OrbitControls`·`ContactShadows`·`RoundedBox` 등 |
| `@types/three` | 최신(dev) | 타입 |

파일 구성(예정):
```
src/house3d/
  House3DView.tsx   <Canvas> + 조명 + 카메라 (기본 내보내기 → React.lazy 로 불러옴)
  models.tsx        Home / Officetel / Shop 모양 컴포넌트 (props: 지붕 색 등)
  sun.ts            (2차) 위경도·시각 → 해 방향
```
- `TransportCard.tsx` 의 `House3D` 는 `<Suspense fallback={SVG 집}>` 으로 감싸 3D 를 늦게 불러온다.

## 8. 성능 기준 (지켜야 할 것)

- **지도 첫 화면이 느려지지 않는다**: 3D 코드는 `React.lazy` 로 따로 묶어(별도 js 파일) 카드가 보일 때 내려받는다. 빌드 후 첫 화면 js 크기가 지금과 거의 같아야 한다.
- 화질: `dpr={[1, 2]}`(휴대폰 고해상도 상한), 그림자 맵 512.
- 그리기: 회전 중에만 다시 그리고, 탭이 숨겨지거나 카드가 화면 밖이면 멈춘다.
- 도형 수: 집 한 채에 메시 30개 이하.
- 확인: 휴대폰 폭(375px)·1320px·넓은 화면에서 원 안에 잘 들어오는지, 넘기기(Swipe)와 충돌 없는지.
