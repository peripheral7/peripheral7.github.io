# 여기살까? — 3D 집(R3F) 기획안

2026-10-14 초안. **방법 A: 코드로 도형을 조합해 집을 만든다**(사진 → 3D 변환은 다음 단계, 9절).
목표는 두 가지 — ① 교통평점 카드의 집 그림을 실제로 돌려 볼 수 있는 3D로 바꾸고, ② 그 과정에서 R3F를 익힌다.

> 표시 ☐ = 아직 정하지 않음(사용자 결정). 정하면 ☑ 로 바꾸고 내용을 적는다.

---

## 1. 지금 상태 (출발점)

- 교통평점 카드 가운데(`TransportCard.tsx` `House3D`)에 **아이소메트릭 SVG 집**이 있다 — 146×134px, 지름 184px 원(종합 점수 호) 안, 지붕 색 = 순위(1위 `#3f9a62` → 2위 `#5e8f9e` → 3위 `#8a7fa8` → 4위 이하 `#a08868`).
- 벽 = 따뜻한 회백색(`#f4f1ea` ~ `#c8c1b2`), 테두리 `#b9b2a3`, 문 `#6f5a43`, 창 `#cfe3ee`, 굴뚝 `#b9a58a`, 바닥 그림자 타원.
- 후보지 자료(`data.ts` `Candidate`)에 있는 것: 이름·주소·위경도·보증금/월세/관리비·**용도**(`use`: 주택 / 주거용 오피스텔 / 상가·기타). **층수·면적·향은 없다.**

## 2. 어디에 보여 줄지

| 단계 | 자리 | 내용 |
|---|---|---|
| 1차 | 교통평점 카드의 원 안(SVG 자리 그대로) | 같은 크기·같은 색으로 3D 집.  |
| 2차(10-14 ☑) | 원(집)을 누르면 **화면 오른쪽 창**(넓은 화면) — 뒤 배경은 흐리게(blur 6px) | 크게 그린 집 · 끌어서 돌리기·휠로 확대 · 장식마다 까닭("🚏 버스 정류장 — 라이프스타일 대중교통 95%") |

- 큰 창: 계산 방식 창과 같은 `.overlay` + `.drawer`(오른쪽) + `.house-overlay`(흐림)·`.house-drawer`. **배경을 누르면 닫힘**(Esc·× 도). 집을 돌리다 창 밖에서 손을 떼도 닫히지 않는다(누르기 시작한 곳이 배경일 때만 닫음).
- 휴대폰(좁은 화면)은 카드에 집·원을 그리지 않으므로(useNarrow) 큰 창도 없다.
- 해 방향(5절)은 아직.
- SVG 집은 지우지 않는다 → **3D를 불러오는 동안·WebGL이 안 되는 기기·"움직임 줄이기" 설정**일 때 그대로 보여 준다.

## 3. 무엇을 보여 줄지 (집 모양 규칙)

10-14 2차 수정: **바닥을 정사각형에 가깝게**(박공 주택이 가로로 길어 보이던 것), **한국식 평지붕 주택·적벽돌 다가구 추가**, **상가 모양 삭제**. 크기는 미터 단위, 화면 맞춤은 House3DView 가 자동.

| 모양(`HouseKind`) | 모습 | 크기(가로×깊이×높이) | 쓰는 때 |
|---|---|---|---|
| 박공지붕 주택 `home` | 벽 상자 + 삼각 지붕 두 장 + 현관문·앞 창 1·옆 창 2 + 굴뚝. **벽 7.4 × 7.4 정사각형, 처마를 사방 0.45m 로 같게 → 위에서 본 지붕도 8.3 × 8.3**(10-14 3차: 처마를 앞뒤로만 길게 내밀어 세로로 긴 집처럼 보이던 것) | 7.4 × 7.4 × 3.2 + 지붕 2.6 | 용도 = 주택(기본) |
| 평지붕 주택 `flat` | 한국 양옥·다가구: 2층, 층 사이 띠, 흰 창틀 + **1층 방범창**, 현관 차양, 옥상 = 난간 + **옥탑 계단실 + 스테인리스 물탱크 + 장독대(항아리 셋)** | 7.2 × 7.2 × 6.2 | 용도 = 상가·기타 |
| 적벽돌 다가구 `brick` | 80·90년대 빨간 벽돌집: 3층, **벽돌 무늬(캔버스로 그린 텍스처)**, 층 사이 흰 띠, 흰 창틀 + 1층 방범창, 현관 차양, 옥상 난간 + 물탱크 | 7.4 × 7.4 × 8.7 | (후보지별 고르기 전까지는 시험 주소로만) |
| 주거용 오피스텔 `officetel` | 평지붕 직육면체, 층마다 가로 창 띠, 옥상 덮개·기계실 | 7 × 7 × 15 (5층) | 용도 = 주거용 오피스텔 |

- 지붕(평지붕은 옥상 바닥·난간 덮개) 색 = 순위 색(1절, SVG 와 같은 값).
- 바닥: 둥근 잔디 판(옅은 초록 회색) + 부드러운 그림자. 반지름 = 장식 없음 6.6m · 장식 있음 8.2m · 공원 9.4m.
- ~~상가·기타 = 낮은 상자 + 통유리 + 차양~~ → 삭제(10-14). 상가·기타 용도는 평지붕 주택으로 보인다.
- 벽돌 텍스처: 256px 캔버스 한 장 = 2m × 2m(8켜, 켜당 25cm, 벽돌 50cm, 켜마다 반 장 엇갈림), 벽돌 색은 고정 씨앗 난수로 조금씩 달리(다시 그려도 같은 무늬). 실제 벽돌보다 크다 — 원 안에서 무늬가 보이게.

### 3-1. 둘레 장식(옵션 오브젝트, 10-14)

후보지 특성에 따라 집 둘레에 붙는다(`src/house3d/spec.ts` 규칙, `options.tsx` 모양). 장식은 실제보다 1.3~1.5배 크게 — 실제 크기면 원 안에서 몇 픽셀이다.

| 장식(`HouseOption`) | 모습 | 자동으로 붙는 조건(지금) |
|---|---|---|
| 🌲 `tree` | 뾰족한 나무 한 그루 | 종합 1위 |
| 🌳 `park` | 판 가장자리를 도는 **산책길**(모래색 고리) + 둥근 나무 7그루 + 뾰족한 나무 1 + 벤치 | 입지 요인 공원 점수 ≥ 7 |
| ☕ `cafe` | **작은 원형 테이블**(흰 상판·검은 다리) + **라탄 의자 둘**(엇갈려 짠 무늬 텍스처, 반원 등받이) + **에스프레소**(받침·잔·크레마, 1.8배) | 도보 5분 안 카페 ≥ 50곳(상권 "충분" 기준) |
| 🐈 `cat` | 앉은 치즈 태비 고양이(흰 가슴·귀·눈·몸을 감싼 꼬리) | 평화로움 점수 ≥ 9(조용한 동네) |
| 📚 `library` | 동네 책장 상자(기둥 + 지붕 + 유리 + 색색 책등) | 도서관 점수 ≥ 8 |
| 🚏 `bus` | 버스 정류장(초록 표지 + 지붕 있는 벤치) | **라이프스타일** 대중교통 비율 ≥ 30% |
| 🚗 `car` | 자동차(주황 = 차량 수단 색) | 라이프스타일 차량 비율 ≥ 30% |
| 🚲 `bike` | 자전거(보라 = 자전거 수단 색) | 라이프스타일 자전거 비율 ≥ 30%, 또는 자전거 사용 켬 |
| 🚶 `walk` | 횡단보도(흰 줄 다섯) + 파란 보행자 표지 | 라이프스타일 도보 비율 ≥ 30% |

- 라이프스타일 장식(10-14 3차): ⚙ 에서 고른 라이프스타일의 **지금 수단 비율**(세부설정으로 바꾼 값 포함, `pref.weights`)로 정한다 — 🚇 대중교통 출퇴근 → 🚏 · 🚗 자차 출퇴근 → 🚗 · 🚶 걸어서 동네 생활 → 🚶 · 🚲 자전거 생활 → 🚲. 비율을 반반으로 바꾸면 둘 다. 방문자가 고른 것이라 **칸을 가장 먼저** 차지한다.
- 칸이 모자라 빠진 장식은 큰 창 설명에서도 뺀다(`placeOptions` 는 three 없는 spec.ts 에 있다).

- 집 모양은 **방문자가 고르지 않는다**(사용자 결정 10-14) — 용도로만 정해지고, 벽돌집은 시험 주소로만 보인다.
- **자리**: 집 둘레 다섯 칸(카메라에서 보이는 쪽) — A 화면 왼쪽 · B 현관 앞 · C 아래 · D 오른쪽 아래 · E 오른쪽. 장식마다 좋아하는 칸 순서가 있고(카페 C → 고양이 B → 나무 A …), 앞 순서 장식부터 차지, 다 차면 빠진다(최대 5개). 공원은 칸 대신 가장자리 전체.
- 모든 장식은 앞(+z)이 카메라 쪽을 보게 45° 돌려 세운다 → 자전거·자동차는 옆모습으로 보인다.
- **시험·구경 주소**: `?house=brick&opts=park,library,bike,car,bus` — 모든 후보지가 그 모양·장식으로(`house` = home·flat·brick·officetel, `opts` = 위 표의 영문, 비우면 `opts=` 장식 없음). 예) <http://localhost:5173/WhereTo/?house=flat&opts=cat,cafe,tree>

## 4. 조작

| 상황 | 동작 |
|---|---|
| 카드 안(1차) | **회전 없음**(고정 각도, 바뀔 때만 다시 그림). **끌기는 막는다**(캔버스 pointer-events: none) — 카드는 좌우로 끌면 후보지가 넘어가므로(UI-UX 3-1 Swipe) 겹치면 안 된다 |
| 큰 창(2차 ☑) | 끌어서 돌리기(drei `OrbitControls`, 감속 0.12), 휠/두 손가락으로 확대(맞춘 크기의 0.8~3배), 기울기 0.2~1.35 rad(땅 밑·바로 위 못 감), 옆으로 옮기기 끔. 돌리기 중심 = 화면 맞춤 가운데 점 |
| 큰 창 이벤트 함정 | 창은 포털이지만 React 이벤트는 카드(Swipe)로 올라간다 → `pointerdown`·`click` 만 창 바깥에서 멈춘다. **`pointermove`·`pointerup` 은 멈추면 안 된다** — OrbitControls 가 document 에서 듣는다(멈췄더니 돌리기가 안 됐다) |
| 후보지를 넘길 때 | 모양·지붕 색이 바뀌면 0.3초 동안 부드럽게(크기 줄었다 커지기) |
| "움직임 줄이기"(`prefers-reduced-motion`) | 넘길 때 커지기도 생략 |

## 5. 해 방향 (2차, 배우기 좋은 덤)

- 후보지 위경도 + 지금 날짜·시각으로 해의 높이·방위를 계산해 조명(`directionalLight`)을 그 방향에 둔다 → 그림자가 실제 해 방향으로 진다.
- 창 아래 시각 막대(6시~20시)를 움직이면 해가 돈다. 집은 정남을 바라본다고 가정(향 자료가 없으므로 "가정" 꼬리표를 단다).

## 6. 분위기 (톤앤매너)

- UI-UX.md 1절의 밝은 테마를 따른다: 배경 투명(카드 흰색이 비치게), 장난감 같은 **로우폴리·무광** 재질(`meshStandardMaterial`, roughness 0.8 안팎), 테두리 선은 없음.
- 조명: 은은한 전체광 + 해 한 개 + 부드러운 그림자. 지나친 반사·네온·후처리 효과(블룸 등)는 쓰지 않는다 — 카드의 점수와 막대가 주인공이다.
- 카메라: 1차는 SVG 와 비슷한 아이소메트릭 느낌(약간 위에서, 왼쪽 앞).

## 7. 기술 구성

| 패키지 | 버전 | 쓰임 |
|---|---|---|
| `three` | **0.172** | 3D 엔진 — drei 9 와 같은 시기 판으로 고정(최신 0.18x 는 drei 9 와 안 맞을 수 있음) |
| `@react-three/fiber` | **8.x** | Three.js를 React 컴포넌트로(`<Canvas>`, `<mesh>`) — v9 는 React 19 필요, 여기는 React 18 |
| `@react-three/drei` | **9.122** | `OrbitControls`(큰 창에서만) |
| `@types/three` | 0.172(dev) | 타입 |

파일 구성(1차 완료 — sun.ts 는 2차):
```
src/house3d/
  House3DView.tsx   <Canvas> + 조명 + 카메라 (기본 내보내기 → React.lazy 로 불러옴)
  models.tsx        Home / FlatHouse / BrickHouse / Officetel / Ground + 공용 Box·Win·Parapet·useCanvasTexture(벽돌 무늬)
  options.tsx       둘레 장식(Cat·CafeSet·Park·Library·Bike·Car·BusStop·Conifer) + 칸 배정(placeOptions) + Rod(두 점 잇는 막대)
  spec.ts           후보지 → { 모양, 지붕 색, 장식 } (자동 규칙 + ?house= ?opts= 덮어쓰기, three 없음 — 카드가 부름)
  colors.ts         순위 → 지붕 색 (SVG 집과 공용, three 없음)
  sun.ts            (2차) 위경도·시각 → 해 방향
```
- `TransportCard.tsx` 의 `HouseRing` 이 `<Suspense fallback={SVG 집}>` 으로 감싸 3D 를 늦게 불러온다. WebGL 이 없으면(`canWebGL`) 또는 오류가 나면(`GLBoundary`) SVG 집.
- 화면 맞춤: 모든 꼭짓점을 카메라 좌표로 옮겨 가로·세로 범위를 잰 뒤 정사영 카메라의 `zoom`·위치를 정한다(모양이 바뀌어도 원 안에 꽉 차게). `Box3` 는 둥근 판의 네모 모서리까지 재서 쓰지 않음.
- 색: `<Canvas flat>`(톤 매핑 없음) — 지붕 색이 SVG·화면 나머지와 같은 값으로 보인다.
- 크기 재기: `resize={{ offsetSize: true }}` — 카드가 기울며 들어오는 중(Swipe)에 재면 캔버스가 커지던 문제 방지.

## 8. 성능 기준 (지켜야 할 것)

- **지도 첫 화면이 느려지지 않는다**: 3D 코드는 `React.lazy` 로 따로 묶어(별도 js 파일) 카드가 보일 때 내려받는다. 빌드 후 첫 화면 js 크기가 지금과 거의 같아야 한다.
- 화질: `dpr={[1, 2]}`(휴대폰 고해상도 상한), 그림자 맵 512.
- 그리기: `frameloop="demand"` — 바뀔 때(후보지·크기)와 0.3초 커지기 동안만 그린다.
- 1차 결과(10-14 빌드): 첫 화면 js 608KB(그대로), 3D 묶음 `House3DView-*.js` 830KB(gzip 223KB) — 카드가 그려질 때 따로 내려받음.
- 도형 수: 집 한 채 메시 30~70개(벽돌집 창·방범창 포함) + 장식 최대 약 80개 — 정지 화면이라 부담 없음.
- 확인: 휴대폰 폭(375px)·1320px·넓은 화면에서 원 안에 잘 들어오는지, 넘기기(Swipe)와 충돌 없는지.
