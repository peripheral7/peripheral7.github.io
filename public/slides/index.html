슬라이드 웹페이지

PPT처럼 넘기고, 슬라이드 안에 다른 페이지를 넣는다

→ ← PageUp / PageDown 이동  ·  F 전체 화면  ·  O 목록  ·  마우스를 움직이면 도구줄

할 수 있는 것

  • 키보드·리모컨(PageUp / PageDown)으로 한 장씩 넘긴다
  • 슬라이드 안에 다른 웹페이지를 넣는다 — 시험 시계 같은 우리 페이지도, 외부 사이트도
  • 항목이 한 줄씩 나타나게 한다 (지금 이 화면처럼)
  • 흰/검은 바탕, 고딕/세리프 글꼴 전환 · 인쇄하면 한 쪽에 한 장

슬라이드 추가하는 법

  1. index.html 을 복사해 새 폴더에 둔다
    public/slides/내덱/index.html
  2. 글만 바꾸고, 장을 늘리려면 오른쪽 블록을 복사한다
  3. 커밋·푸시하면 몇 분 뒤 /slides/내덱/ 에 올라간다
<section class="slide">
  <h2>제목</h2>
  <ul>
    <li>내용</li>
    <li class="step">추가</li>
  </ul>
</section>

다른 페이지 넣기 ① 슬라이드 전체

  • data-src 에 주소를 쓰면 그 페이지가 화면을 가득 채운다
  • 이 사이트 안은 /clock/ 처럼 / 로 시작
  • 다음 장이 임베드면 미리 불러 둔다
<section class="slide"
         data-src="/clock/"
         data-title="시험 시계">
</section>

다른 페이지 넣기 ② 일부 칸

  • 글과 함께 한쪽 칸에만 넣을 수 있다
  • 오른쪽은 외부 사이트(OpenStreetMap)
<div class="embed-box"
     data-src="https://…"
     style="height:520px"></div>

키와 단추

키동작
→ ↓ PageDown 스페이스다음 (남은 항목이 있으면 한 줄 더)
← ↑ PageUp Shift+스페이스이전
Home / End처음 / 마지막 장
숫자 + Enter그 번호의 장으로
O슬라이드 목록
F · D · T전체 화면 · 흰/검은 바탕 · 고딕/세리프
Esc도구줄 보이기 · 목록 닫기

임베드가 안 보이거나 키가 안 먹을 때

  • 일부 사이트는 다른 페이지 안에 넣는 것을 막는다 → 도구줄의 Open 으로 새 탭에서 열거나, 그 사이트의 임베드용 주소(예: YouTube 는 /embed/영상ID)를 쓴다
  • 이 사이트의 페이지는 안쪽을 클릭해도 ← → PageUp PageDown 이 그대로 먹는다
  • 외부 사이트는 클릭하면 키가 그 페이지로 들어간다 → 그동안 도구줄(Prev / Next)이 계속 보이니 그걸 누른다
