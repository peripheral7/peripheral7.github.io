7.1 THE CAPM

가정(assumptions)과 세 가지 결과(results)

투자자 가정

  • 평균·분산만 본다 (Markowitz)
  • 같은 투자기간 (same horizon)
  • 같은 추정치 — 동질적 기대 (homogeneous expectations)
  • 가격 수용자 (price takers)

시장 가정

  • 모든 자산 거래·분할 가능, 하나의 rf 로 차입·대출
  • 세금 없음(동일) · 거래비용 없음

모형은 가정의 현실성이 아니라 예측의 정확성으로 평가한다.

결과 1 · 모두 시장 포트폴리오 M

같은 프런티어 + 같은 rf → 같은 접점 포트폴리오 = 시가총액 가중 M. 차이는 M 과 rf 의 비율뿐 → 모두 CML 위.

결과 2 · 수동 전략이 효율적

뮤추얼펀드 정리(mutual fund theorem): 인덱스펀드 + T-bill 이면 충분. 수동 투자자는 무임승차(free-rider).

결과 3 · 시장위험프리미엄

E(rM) − rf = Ā · σM2

7.1 THE CAPM

베타(beta)와 기대수익률–베타 관계

βi = Cov(ri, rM) / σM2 = ρiM σi / σM

E(ri) = rf + βi [E(rM) − rf]

왜 β인가: 분산된 포트폴리오 안에서 주식의 위험은 시장 분산에 대한 기여 wi·Cov(ri, rM) 뿐.

rf = 시간가치 · βi = 위험의 양 · E(rM) − rf = 위험의 가격(모든 자산 동일)

식에 자산 자신의 σ 는 없다 — 분산 가능 위험(diversifiable risk)은 보상받지 못한다.

β읽는 법
β > 1공격적(aggressive) — 시장 움직임 증폭
β = 1시장과 1:1 (시장 포트폴리오)
0 < β < 1방어적(defensive) — 유틸리티·필수소비재
β = 0체계적 위험 없음 → σ 가 커도 rf 만
β < 0헤지 자산 → E(r) < rf

7.1 THE CAPM

SML 과 CML — 헷갈리지 말 것

자본시장선 CML (Capital Market Line)증권시장선 SML (Security Market Line)
가로축표준편차 σ (총위험)베타 β (체계적 위험)
선 위에 오는 것효율적 포트폴리오만 (M 과 rf 의 조합)모든 증권·포트폴리오 (효율적이든 아니든)
기울기[E(rM) − rf] / σM = M 의 샤프비율E(rM) − rf = 시장위험프리미엄
선 아래면비효율적 — 개별 주식이면 정상고평가(overpriced) — 진짜 가격 오류 신호
쓰임내 완전 포트폴리오(complete portfolio) 고르기자산 가격 평가 · 기준수익률(hurdle rate)

SML: 절편 rf, 기울기 MRP, 반드시 점 (β = 1, E(rM)) 을 지난다.

rf 만 오르고 E(rM) 이 그대로면 절편↑ 기울기↓ → SML 이 β = 1 을 축으로 돈다.

7.1 THE CAPM

알파(alpha) 판단 규칙과 포트폴리오 베타

α = E(r)forecast − [rf + β(E(rM) − rf)]

E(r)forecast = [E(P1) − P0 + D1] / P0

α위치판단 → 조정
α > 0SML 위저평가 BUY → 가격↑, E(r)↓
α < 0SML 아래고평가 SELL → 가격↓, E(r)↑
α = 0SML 위공정가격 (균형에서는 모두 0)

α = 0 이 되는 가격: P0 = [E(P1) + D1] / (1 + 요구수익률)

βP = Σ wi βi

분산과 달리 β 는 가중평균 → E(rP) = rf + βP·MRP (개별 CAPM 수익률의 가중평균과 같다)

목표 β 맞추기: 포트폴리오 비중 w = βtarget / βP, 나머지 1 − w 는 rf (음수면 차입)

7.2 THE CAPM AND INDEX MODELS

지수모형(index model), SCL, 위험 분해

Ri,t = αi + βi RM,t + ei,t

  • R = 초과수익률(r − rf) — 관측 가능, OLS 로 추정 (보통 60개월)
  • 회귀선 = 증권특성선 SCL (security characteristic line): 기울기 β, 절편 α (CAPM 예측 α = 0), 세로 거리 = 잔차 e
  • t = 추정치 / 표준오차, p < 0.05 면 유의 · 95% 구간 ≈ β ± 2·se
  • 조정 베타 βadj = (2/3)βsample + 1/3 (1 쪽으로 당김)

σi2 = βi2σM2 + σ2(ei)

총위험 = 체계적(systematic) + 기업 고유(firm-specific)

R2 = β2σM2 / σi2

R² = 분산 중 체계적 비율. 개별 주식 0.20–0.40, 분산된 펀드 0.90 이상

강의 예: β = 1.20, σM = 5%, σ(e) = 6% → 36 + 36 = 72 (%²), R² = 0.50

7.3 THE CAPM AND THE REAL WORLD

Roll's critique 와 너무 평평한 SML

Roll (1977)

  • 검증 가능한 유일한 함의 = 진짜 시장 포트폴리오가 평균-분산 효율적
  • 진짜 M(채권·부동산·인적자본까지)은 관측 불가
  • 대용치(proxy, 예: S&P 500)로 검정 = 대용치의 효율성 검정
  • 효율적인 대용치면 β–수익률 관계가 항등식처럼 성립 → 순환

대응: 지수모형을 유용한 근사로 보고 설명·예측력으로 평가

실증: SML 이 너무 평평하다

  • 절편이 너무 높다 → 저β 자산이 CAPM 예측보다 더 벌었다
  • 기울기가 너무 평평 → 고β 자산이 예측보다 덜 벌었다
  • β 가 전부가 아니다 → 규모·가치·모멘텀

저베타 이상현상(low-beta anomaly) → betting-against-beta, 저변동성 펀드

7.3 THE CAPM AND THE REAL WORLD

이상현상(anomalies)과 CAPM 이 살아남는 이유

이상현상내용 (β 가 설명 못 하는 것)근거
규모 (size)소형주가 β 에 비해 높은 수익Banz (1981)
가치 (value)높은 장부/시장(B/M) 가치주 > 낮은 B/M 성장주Fama-French (1992)
모멘텀 (momentum)지난 3–12개월 승자가 몇 달 더 이긴다Jegadeesh-Titman (1993)
수익성·투자수익성 높고 보수적으로 투자하는 기업이 더 높은 수익Fama-French (2015)

두 해석: (a) 시장 비효율 → 가격 오류  /  (b) 시장은 효율적, 위험 요인이 여럿 → 7.4 는 (b)

그래도 CAPM: 옳은 정성적 결론(체계적 위험만 보상) · 규율 있는 기준(benchmark) · 단순하고 조작하기 어렵다(요율 심사·법정) · 경쟁 모형도 요인 프리미엄이 불안정

7.4 MULTIFACTOR MODELS

다요인 모형 — Fama-French 와 그 너머

E(ri) − rf = βM[E(rM) − rf] + βSMBE(SMB) + βHMLE(HML)

요인 / 로딩뜻
SMB (Small Minus Big)소형주 − 대형주 수익률
HML (High Minus Low)고 B/M(가치) − 저 B/M(성장)
βSMB > 0 / < 0소형주 기울기 / 대형주 기울기
βHML > 0 / < 0가치주 기울기 / 성장주 기울기
  • Carhart 4요인 (1997): + 모멘텀 UMD — 펀드 성과평가 표준
  • FF 5요인 (2015): + 수익성 RMW, 투자 CMA → 미국 자료에서 HML 거의 중복
  • 요인 동물원(factor zoo): 수백 개, 표본 밖·발표 후 약해짐
  • CAPM α > 0 인데 FF α < 0 → "실력"이 아니라 소형·가치 기울기(ETF 로 싸게 살 수 있음)

7.5 ARBITRAGE PRICING THEORY

차익거래(arbitrage)와 APT

차익거래 = 순투자 0 + 위험 0(요인 노출 상쇄) + 모든 상태에서 확실한 이익. "높은 기대수익"이나 α > 0 은 차익거래가 아니다.

잘 분산된 포트폴리오로 하는 순서

  1. 같은 β 의 기준(benchmark): w 를 M, 1 − w 를 T-bill (w = β)
  2. E(r) 비교 → 높은 쪽 매수, 낮은 쪽 공매도(같은 금액)
  3. 순투자 0, 노출 0, 이익 = 수익률 차 × 금액
  4. 무한히 키움 → 가격 조정 → 차이 소멸

E(ri) = rf + βi1RP1 + … + βikRPk

요인 프리미엄은 음수일 수 있다: 나쁜 상태(예: 예상 밖 인플레이션)에서 돈을 주는 노출은 보험 → 낮은 수익을 받아들인다.

강의 Ex.12: 4% + 1.20(6%) + 0.70(−7%) = 6.3% (생산 요인만 쓰면 11.2%)

7.5 ARBITRAGE PRICING THEORY

APT 대 CAPM

CAPMAPT
핵심 가정모든 투자자가 평균-분산 최적화요인모형 세계에서 무차익
합리적이어야 하는 사람사실상 모든 투자자자금력 있는 소수의 차익거래자
요인 수정확히 하나: 시장 포트폴리오몇 개든 — 이론은 말하지 않음
적용 대상모든 증권에 정확히잘 분산된 포트폴리오
약점강한 가정, 실증적으로 기각어떤 요인이 중요한지 침묵

결론은 같은 꼴: 기대수익률 = rf + Σ(요인 베타 × 요인 프리미엄). CAPM 은 요인이 시장 하나인 특수한 경우처럼 보인다.

헷갈리는 쌍 비교표

쌍구분하는 기준
σ 대 βσ = 총위험(CML 축) · β = 체계적 위험(SML 축, 가격 결정)
CML 아래 대 SML 아래비효율적(개별 주식이면 정상) 대 고평가(SELL 신호)
SCL 대 SML한 주식의 시계열 회귀선(기울기 β) 대 모든 자산의 E(r)–β 선(기울기 MRP)
β 대 R²시장에 대한 민감도 대 분산 중 체계적 비율 (β 가 커도 R² 는 낮을 수 있다)
Cov 대 ρβ = Cov/σM2 = ρσi/σM — Cov 는 이미 σiσM 를 품고 있다
CAPM α 대 FF α기준이 다르다: 요인 기울기를 빼면 "실력"이 사라질 수 있다
α > 0 대 차익거래α 는 위험이 남은 기대 초과수익 · 차익거래는 순투자 0·위험 0·확실한 이익
% 대 소수Ā σM2 는 소수로 (2 × 0.20² = 0.08) · 분산은 %² 로 써도 되지만 단위를 섞지 말 것

Q1 · 시장위험프리미엄

투자자들의 평균 위험회피계수 Ā = 3, 시장 포트폴리오의 표준편차 σM = 18% 이다. (a) 균형 시장위험프리미엄(market risk premium)은? (b) σM 만 27% 로 오르면 프리미엄은 몇 배가 되나?

공식 E(rM) − rf = Ā · σM2 (σ 는 소수로)
(a) 3 × 0.182 = 3 × 0.0324 = 0.0972 = 9.72% · BA II Plus: 0.18 x² × 3 = 0.0972
(b) 3 × 0.272 = 0.2187 = 21.87% → (27/18)2 = 2.25배. 프리미엄은 σ 가 아니라 분산에 비례한다(σ 1.5배 → 2.25배).

Q2 · 베타 계산 (두 공식)

주식 K: σK = 40%, σM = 16%, ρKM = 0.48. 공분산 Cov(rK, rM) 과 βK 를 구하고 두 번째 공식으로 확인하라. K 는 시장보다 훨씬 변동성이 큰데 β 는 어떻게 읽나?

Step 1 Cov = ρσKσM = 0.48 × 0.40 × 0.16 = 0.03072 (= 307.2 %²)
Step 2 βK = Cov / σM2 = 0.03072 / 0.0256 = 1.20 · BA II Plus: 0.16 x² = 0.0256 → 0.03072 ÷ 0.0256 = 1.2
확인 β = ρσK/σM = 0.48 × 40 / 16 = 1.20 ✓
해석 σK/σM = 2.5배지만 ρ = 0.48 이라 β 는 1.20 — 공격적(aggressive)이지만 총변동성의 상당 부분은 기업 고유 위험이라 가격에 반영되지 않는다.

Q4 · SML 과 CML 로 판단하기

주식 X 의 예측 기대수익률은 SML 이 요구하는 값보다 1.5%p 높다. 그런데 (σ, E(r)) 그림에서 X 는 CML 보다 한참 아래에 있다. (a) X 는 고평가인가 저평가인가? (b) CML 아래라는 사실은 무엇을 뜻하나? (c) 가격 판단에는 어느 선을 쓰나?

(a) SML 위 1.5%p → α = +1.5% → 저평가(underpriced), BUY. 매수 압력으로 가격↑, 기대수익률↓ → SML 로 돌아간다.
(b) CML 아래 = 비효율적(inefficient) 포트폴리오라는 뜻일 뿐. 단일 종목은 기업 고유 위험 때문에 거의 늘 CML 아래 — 가격 오류 신호가 아니다.
(c) 가격 판단·기준수익률 = SML(가로축 β, 모든 자산). CML(가로축 σ, 효율적 포트폴리오만)은 자기 완전 포트폴리오를 고를 때 쓴다.

Q5 · 알파와 매수·매도

주식 L: 현재가 P0 = $40, 1년 뒤 예상가격 E(P1) = $43, 예상배당 D1 = $1.00, β = 0.80, rf = 3.5%, E(rM) = 9.5%. (a) 예측 보유기간수익률 (b) CAPM 요구수익률 (c) α 와 판단 (d) α = 0 이 되는 현재가격은?

(a) [E(P1) − P0 + D1] / P0 = (43 − 40 + 1.00) / 40 = 4.00 / 40 = 10.0%
(b) 3.5% + 0.80 × (9.5% − 3.5%) = 3.5% + 4.8% = 8.3%
(c) α = 10.0% − 8.3% = +1.7% → SML 위 → 저평가 → BUY
(d) P0 = (43 + 1.00) / 1.083 = $40.63 · BA II Plus: 44 ÷ 1.083 = 40.63 — 매수 압력이 가격을 $40.63 까지 올리면 α = 0.

Q6 · 포트폴리오 베타

포트폴리오: 주식 A 50% (β = 1.40), 주식 B 30% (β = 0.70), T-bill 20%. rf = 4%, E(rM) = 10%. βP 와 E(rP) 를 구하고, 개별 CAPM 수익률의 가중평균으로 확인하라.

Step 1 βP = Σwiβi = 0.50(1.40) + 0.30(0.70) + 0.20(0) = 0.70 + 0.21 + 0 = 0.91
Step 2 E(rP) = 4% + 0.91 × 6% = 4% + 5.46% = 9.46%
확인 A: 4 + 1.40(6) = 12.4% · B: 4 + 0.70(6) = 8.2% · T-bill: 4% → 0.5(12.4) + 0.3(8.2) + 0.2(4) = 6.2 + 2.46 + 0.8 = 9.46% ✓
포인트 β 는 가중평균이라 그대로 더해진다(분산은 공분산 항 때문에 그렇지 않다).

Q7 · 목표 베타 맞추기

펀드 F 의 β = 1.25. rf = 3%, 시장위험프리미엄 6%. 펀드와 무위험자산만으로 (a) β = 0.75 (b) β = 1.50 을 만들려면 펀드 비중은? 각 기대수익률은?

규칙 w × βF + (1 − w) × 0 = βtarget → w = βtarget / βF
(a) w = 0.75 / 1.25 = 0.60 → 펀드 60%, T-bill 40% (대출) · E(r) = 3% + 0.75 × 6% = 7.5%
(b) w = 1.50 / 1.25 = 1.20 → 펀드 120%, rf 로 20% 차입 · E(r) = 3% + 1.50 × 6% = 12.0%
확인 E(rF) = 3 + 1.25(6) = 10.5% → 1.20(10.5) − 0.20(3) = 12.6 − 0.6 = 12.0% ✓

Q8 · 무위험이자율 변화와 SML

E(rM) = 11% 는 그대로인데 rf 가 3% 에서 5% 로 오른다. β = 0.5, 1.0, 1.5 자산의 요구수익률은 어떻게 바뀌나? SML 의 모양은?

β전: 3% + β(8%)후: 5% + β(6%)변화
0.57.0%8.0%+1.0%p
1.011.0%11.0%0
1.515.0%14.0%−1.0%p
모양 절편 rf 3% → 5%↑, 기울기 MRP 8% → 6%↓ → SML 이 점 (1, 11%) 을 축으로 회전. 평행이동이 아니다.
이유 E(r) = rf(1 − β) + βE(rM) — β < 1 이면 rf 비중이 양(+), β > 1 이면 음(−).

Q9 · 회귀 출력 읽기

60개월 초과수익률 회귀: 절편 α = 0.30%/월 (표준오차 0.40%), 기울기 β = 0.85 (표준오차 0.10). (a) α 는 유의한가? (b) β 는? (c) β 의 95% 구간(t ≈ 2)은? (d) CAPM 은 α 에 대해 무엇을 예측하나?

(a) t = 0.30 / 0.40 = 0.75 < 2 → α = 0 을 기각 못 함 → 종목선택 실력(stock-picking skill)의 통계적 증거 없음
(b) t = 0.85 / 0.10 = 8.5 → β = 0 기각, 유의
(c) 0.85 ± 2 × 0.10 = 0.65 ~ 1.05 — 유의해도 구간이 넓다 → 기준수익률(hurdle rate)이 그만큼 불확실
(d) 회귀식 Ri,t = α + βRM,t + e 에서 CAPM 은 α = 0 을 예측한다. 기울기 = β, 각 달의 세로 거리 = 잔차 e (SCL).

Q10 · 위험 분해와 R²

연간 초과수익률 회귀: β = 1.10, σM = 20%, σ(e) = 30%. (a) 체계적 분산과 체계적 표준편차 (b) 총분산과 총표준편차 (c) R² 를 구하라.

공식 σ2 = β2σM2 + σ2(e),   R2 = β2σM2 / σ2 (모두 % 단위, 분산은 %²)
(a) β2σM2 = 1.21 × 400 = 484 (%²), 체계적 SD = 1.10 × 20 = 22%
(b) σ2 = 484 + 302 = 484 + 900 = 1,384 (%²), σ = √1,384 = 37.20% · BA II Plus: 1.1 x² × 400 = 484 + 900 = 1384 √x
(c) R2 = 484 / 1,384 = 0.350 → 분산의 35% 만 체계적, 65% 는 분산 가능(diversifiable) — 개별 주식의 전형적 범위(0.20–0.40).

Q11 · 조정 베타 (adjusted beta)

표본 베타가 1.50 인 주식 G 와 0.60 인 주식 U 의 조정 베타를 공식 βadj = (2/3)βsample + 1/3 로 구하고, 무엇을 하는 조정인지 설명하라.

G (2/3)(1.50) + 1/3 = 1.000 + 0.333 = 1.333
U (2/3)(0.60) + 1/3 = 0.400 + 0.333 = 0.733
의미 둘 다 1 쪽으로 당겨진다(1.50↓, 0.60↑). 표본 베타는 추정오차가 크고, 극단값은 다음 기간에 평균 1 쪽으로 돌아가는 경향이 있기 때문.

Q12 · Roll's critique

연구자 1 은 S&P 500 을 시장 포트폴리오로 써서 CAPM 을 검정했더니 β–평균수익률 관계가 맞지 않았다. 연구자 2 는 사후적으로 평균-분산 효율적인 지수를 찾아 관계가 완벽히 맞았다. Roll (1977) 에 따르면 각각 무엇을 보여 주나?

핵심 CAPM 의 유일한 검증 가능 함의 = 진짜 시장 포트폴리오가 효율적이라는 것. 진짜 M(전 세계 주식·채권·부동산·비상장기업·인적자본)은 관측할 수 없다.
연구자 1 S&P 500 이라는 대용치(proxy)가 효율적이지 않다는 것만 보였다 — CAPM 기각이 아니다.
연구자 2 효율적 대용치를 쓰면 β–수익률 관계는 수학적으로 항등식처럼 성립 → 증거가 아니라 순환 논리.
대응 지수모형을 유용한 근사로 보고, 설명력·예측력으로 평가한다.

Q13 · 평평한 SML 과 이상현상

(a) 고전적 횡단면 검정에서 추정 SML 은 CAPM 예측과 비교해 어떻게 다른가? 저β·고β 주식에 대해 무엇을 뜻하나? (b) 다음을 이상현상 이름·근거 논문과 짝지어라: ① 소형주가 β 에 비해 높은 수익 ② 지난 3–12개월 승자가 계속 이김 ③ 고 B/M 주식이 저 B/M 주식을 이김 ④ 수익성 높고 투자가 보수적인 기업이 높은 수익

(a) 절편이 너무 높고 기울기가 너무 평평 → 저β 는 예측보다 더, 고β 는 덜 벌었다 = 저베타 이상현상 → betting-against-beta·저변동성 펀드의 근거
(b) ① 규모(size) — Banz (1981) · ② 모멘텀(momentum) — Jegadeesh-Titman (1993) · ③ 가치(value) — Fama-French (1992) · ④ 수익성·투자 — Fama-French (2015)
해석 (a) 시장 비효율(가격 오류) 또는 (b) 위험 요인이 여럿 — 7.4 의 다요인 모형은 (b) 를 따른다.

Q14 · Fama-French 3요인 대 CAPM

rf = 3%. 요인 프리미엄: 시장 6%, SMB 3%, HML 5%. 펀드 로딩: βM = 0.90, βSMB = 0.50, βHML = 0.60. 펀드는 작년에 11.0% 를 벌었다. (a) 3요인 요구수익률 (b) CAPM 요구수익률 (c) 두 알파와 해석

(a) 3% + 0.90(6%) + 0.50(3%) + 0.60(5%) = 3 + 5.4 + 1.5 + 3.0 = 12.9%
(b) 3% + 0.90(6%) = 3 + 5.4 = 8.4%
(c) CAPM α = 11.0 − 8.4 = +2.6% · 3요인 α = 11.0 − 12.9 = −1.9%
해석 로딩이 SMB +, HML + → 소형·가치 기울기. CAPM 기준의 "초과성과"는 이 체계적 기울기에서 왔고, 3요인 기준으로는 오히려 부진 — 이 기울기는 인덱스 ETF 로 싸게 살 수 있다. 3요인 α 가 더 정보가 많다.

Q15 · 요인 로딩 해석과 확장 모형

(a) 펀드 A: βSMB = +0.6, βHML = +0.5 / 펀드 B: βSMB = −0.3, βHML = −0.7 의 스타일은? (b) FF3 에 모멘텀을 더한 모형과 수익성·투자를 더한 모형의 이름과 요인 기호는? (c) "factor zoo" 문제란?

(a) SMB = 소형 − 대형, HML = 고 B/M(가치) − 저 B/M(성장) → A: 소형 가치(small-cap value) · B: 대형 성장(large-cap growth)
(b) Carhart 4요인 (1997): + UMD(up minus down, 모멘텀) · Fama-French 5요인 (2015): + RMW(수익성), CMA(투자) → 미국 자료에서 HML 이 거의 중복
(c) 발표된 요인이 수백 개, 상당수는 표본 밖에서 재현되지 않고 발표 후 약해진다. 요인을 더하면 과거 적합도는 늘 좋아진다 — 문제는 어느 요인이 미래에도 위험프리미엄을 받는가.

Q16 · 차익거래 (arbitrage)

잘 분산된 포트폴리오 A: β = 1.00, E(r) = 12% / B: β = 0.60, E(r) = 8%. rf = 5%. 차익거래 기회가 있나? $1,000,000 규모의 거래를 보이고, 균형에서 B 의 기대수익률은?

Step 1 같은 β 의 기준 D = 60% A + 40% T-bill → βD = 0.6(1.00) + 0.4(0) = 0.60, E(rD) = 0.6(12) + 0.4(5) = 9.2% > 8% → B 고평가
포지션오늘 현금흐름요인 노출1년 뒤 손익
B 공매도 $1,000,000+$1,000,000−0.60−$80,000
D 매수 ($600,000 A + $400,000 T-bill)−$1,000,000+0.60+$92,000
순(net)$00+$12,000 확실
균형 공매도 압력 → B 가격↓ → E(rB) 가 5% + 0.60 × (12% − 5%) = 9.2% 가 될 때까지 오른다.

Q17 · 다요인 APT

rf = 3%. 요인 1(경기·GDP 서프라이즈): β1 = 1.40, RP1 = +4%. 요인 2(예상 밖 인플레이션): β2 = 0.50, RP2 = −3%. (a) APT 요구수익률 (b) 요인 1 만 쓰는 단일요인 모형과 비교 (c) RP2 가 음수인 이유

(a) E(r) = rf + β1RP1 + β2RP2 = 3% + 1.40(4%) + 0.50(−3%) = 3 + 5.6 − 1.5 = 7.1%
(b) 3% + 5.6% = 8.6% → 인플레이션 헤지를 무시하면 요구수익률을 1.5%p 과대평가
(c) 인플레이션 요인에 대한 노출은 물가가 예상보다 오르는 나쁜 상태에서 돈을 준다 = 보험(hedge). 투자자는 보험의 대가로 더 낮은 기대수익률을 받아들인다 → 프리미엄 음수.

Q18 · APT 대 CAPM

다섯 항목으로 CAPM 과 APT 를 비교하라: 핵심 가정 · 합리적이어야 하는 사람 · 요인 수 · 적용 대상 · 약점. APT 가 "더 약한 가정"이라는 말의 뜻은?

가정 CAPM: 모든 투자자가 평균-분산 최적화 / APT: 요인모형 세계에서 무차익(no-arbitrage)
누가 CAPM: 사실상 모든 투자자 / APT: 자금력 있는 소수의 차익거래자
요인·대상 CAPM: 시장 하나, 모든 증권에 정확히 / APT: 몇 개든(이론은 침묵), 잘 분산된 포트폴리오
약점 CAPM: 강한 가정, 실증적으로 기각 / APT: 어떤 요인이 중요한지 말해 주지 않음
뜻 모두가 최적화할 필요 없이 "공짜 점심은 없다" 하나로 E(r) = rf + ΣβkRPk 를 얻는다.
