11.1Expected return and variance

Key question How do we summarize a return that hasn't happened yet?

E(R) = Σ ps·Rs
σ² = Σ ps·(Rs − E(R))²

Expected return, variance, standard deviation σ = √σ²

11.2Portfolios

Key question What happens to return and risk when we mix? (A 50% + B 50%)

E(RP) = w1E(R1) + w2E(R2) + …

Weighted averageFrom the portfolio's own state returnsSame?
Expected return0.5×25% + 0.5×20% = 22.5%0.5×5% + 0.5×40% = 22.5%Same
Standard deviation0.5×45% + 0.5×10% = 27.5%√0.030625 = 17.5%Different

The two stocks move in opposite directions and offset each other, so risk is below the weighted average — the seed of diversification.

11.2포트폴리오(portfolio)

핵심 질문 섞으면 수익률과 위험이 어떻게 되나? (A 50% + B 50%)

E(RP) = w1E(R1) + w2E(R2) + …

가중평균으로 계산하면포트폴리오 자체 상황별로 계산하면같은가?
기대수익률0.5×25% + 0.5×20% = 22.5%0.5×5% + 0.5×40% = 22.5%같다
표준편차0.5×45% + 0.5×10% = 27.5%√0.030625 = 17.5%다르다

두 주식이 반대로 움직여 서로를 상쇄하므로 위험은 가중평균보다 작다 — 분산투자의 씨앗.

11.3–11.4 Surprise and two kinds of risk

R = E(R) + U   Actual return = expected (already priced in) + unexpected return

Systematic riskUnsystematic risk
Other namesMarket risk, non-diversifiable riskUnique risk, asset-specific risk
ScopeNearly all assetsOne firm or a few
ExamplesInterest rates, inflation, GDP, tax law changesStrike, product failure, lawsuit, fire
In a large portfolioRemainsOffsets and disappears

E.g. expected 25%, actual 30% → U = +5%. Of all the news, only the surprise moves prices.

11.3–11.4 놀람(surprise)과 두 종류의 위험

R = E(R) + U   실제 수익률 = 기대(이미 가격에 반영) + 예상치 못한 부분(unexpected return)

체계적 위험 (systematic risk)비체계적 위험 (unsystematic risk)
다른 이름시장위험, 분산 불가능 위험고유위험, 자산 특유 위험
영향 범위거의 모든 자산한 기업 또는 소수
예금리, 인플레이션, GDP, 세법 변경파업, 제품 실패, 소송, 화재
큰 포트폴리오에서남는다상쇄되어 사라진다

예: 기대 25%, 실제 30% → U = +5%. 가격을 움직이는 건 뉴스 중 놀람뿐.

11.6Beta (β)

Key question How do we measure the risk left after diversifying?

βMeaning
= 1Moves 1:1 with the market
> 1Amplifies market moves (airlines, tech)
0 ~ 1Dampens market moves (utilities, food)
= 0Unrelated to the market

βP = w1β1 + w2β2 + …

40% × 1.60 + 60% × 0.80 = 0.64 + 0.48 = 1.12

Portfolio beta is a weighted average. Standard deviation is not.
A high σ does not mean a high β (gold mining firm).

11.6베타(beta, β)

핵심 질문 분산 뒤에 남는 위험을 어떻게 재나?

β뜻
= 1시장과 1:1로 움직임
> 1시장 변동을 키움 (항공·기술)
0 ~ 1시장 변동을 줄임 (전력·식품)
= 0시장과 무관

βP = w1β1 + w2β2 + …

40% × 1.60 + 60% × 0.80 = 0.64 + 0.48 = 1.12

포트폴리오 베타는 가중평균이 된다. 표준편차는 안 된다.
σ 가 크다고 β 가 큰 것은 아니다(금광회사).

11.7Security market line (SML) and CAPM

Reward-to-risk = (E(Ri) − Rf) / βi  → equal for all assets in equilibrium

E(Ri) = Rf + βi × [E(RM) − Rf]

Rf = 8%, market risk premium 7%βOfferedSML requiredVerdict
Asset A — above SML1.6022%19.2%Undervalued
Asset B — below SML1.2013%16.4%Overvalued

SML slope = market risk premium. Intercept = risk-free rate.

11.7증권시장선(SML)과 CAPM

Reward-to-risk = (E(Ri) − Rf) / βi  → 균형에서는 모든 자산이 같다

E(Ri) = Rf + βi × [E(RM) − Rf]

Rf = 8%, 시장위험프리미엄 7%β제시SML 요구판정
Asset A — SML 위1.6022%19.2%저평가(undervalued)
Asset B — SML 아래1.2013%16.4%고평가(overvalued)

SML 의 기울기 = 시장위험프리미엄(market risk premium). 절편 = 무위험이자율(risk-free rate).

11.8SML and cost of capital → Ch.12

Project's β→SML required return→NPV discount rate→Ch.12 Cost of capital
  • Project above the SML = NPV > 0 — same verdict
  • Discount at the project's β, not the firm's β
  • Ch.12: blend cost of equity RE = Rf + βE(RM − Rf) with cost of debt to get WACC (weighted average cost of capital)

This closes the loop on where the “given” discount rate in Ch.8–9 comes from; Ch.12 extends it to the whole firm.

11.8SML과 자본비용 → Ch.12

프로젝트의 β→SML 요구수익률→NPV 할인율→Ch.12 자본비용(cost of capital)
  • SML 위에 있는 프로젝트 = NPV > 0 — 같은 판정
  • 회사의 β가 아니라 프로젝트의 β로 할인한다
  • Ch.12: 자기자본비용 RE = Rf + βE(RM − Rf) 를 부채비용과 섞어 WACC(가중평균자본비용)를 만든다

Ch.8–9 에서 “주어진” 할인율이 어디서 오는지 여기서 닫히고, Ch.12 에서 회사 전체로 넓힌다.
