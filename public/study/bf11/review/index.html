11.1Expected return — probability-weighted average

Ch.10 averaged what actually happened. Ch.11 averages what could happen, weighted by each state's probability.

E(R) = p1R1 + p2R2 + … + pnRn   (Σp = 1)

StateChanceStock AStock B
Recession0.50−20%+30%
Boom0.50+70%+10%
E(R)25%20%

E(RA) = 0.50 × (−20%) + 0.50 × 70% = −10% + 35% = 25%

E(RB) = 0.50 × 30% + 0.50 × 10% = 15% + 5% = 20%

A's higher expected return does not make it the "better stock" — look at risk (σ).

If a probability is missing, fill it in first as 1 − (sum of the other probabilities).

11.2Portfolio expected return — two paths, same answer

E(RP) = w1E(R1) + w2E(R2) + …   (w = share of money invested, Σw = 1)

Path 1 — average the expected returns

A 50% · B 50%

E(RP) = 0.50 × 25% + 0.50 × 20% = 12.5% + 10% = 22.5%

Path 2 — portfolio return by state

StatepRP
Recession0.500.5(−20%) + 0.5(30%) = +5%

11.2Portfolio risk is not a weighted average

σA = 45%, σB = 10%. The 50/50 portfolio's σ is not 27.5% — compute it from the portfolio's own returns by state.

StatepRPp × (RP − 22.5%)²
Recession0.50+5%0.50 × (−0.175)² = 0.0153125
Boom0.50+40%0.50 × 0.175² = 0.0153125
Variance0.030625

Weighted average would give: 0.50 × 45% + 0.50 × 10% = 27.5%

Actual: σP = √0.030625 = 17.5%

Why smaller? In a recession A↓ and B↑ — they move opposite and offset. This is the seed of diversification.

11.2포트폴리오 위험은 가중평균이 아니다

σA = 45%, σB = 10%. 반반 포트폴리오의 σ는 27.5%가 아니다 — 포트폴리오 자체의 상황별 수익률로 계산한다.

StatepRPp × (RP − 22.5%)²
Recession0.50+5%0.50 × (−0.175)² = 0.0153125
Boom0.50+40%0.50 × 0.175² = 0.0153125

가중평균이라면: 0.50 × 45% + 0.50 × 10% = 27.5%

실제: σP = √0.030625 = 17.5%

왜 작은가? 불황에 A↓ B↑ — 반대로 움직여 서로 상쇄한다. 이것이 분산투자(diversification)의 씨앗이다.

11.3Announcements and surprises — R = E(R) + U

Actual return R = expected return E(R) + unexpected return U

E(R) — already priced in

  • The part the market expected and priced in before the year began
  • If news comes out as expected, it adds no extra return
  • Announcement = expected part + surprise

U — the surprise

  • Everything unexpected. Only this part moves the price
  • Averages 0 over many periods — if its sign were predictable, it would already be in E(R)

Lecture example: the market expects A to return 25% this year; actual is 30% → U = 30% − 25% = +5%. Only this 5%p was something nobody could plan for.

11.3발표와 놀람 — R = E(R) + U

실제 수익률 R = 기대수익률 E(R) + 예상치 못한 수익률 U

E(R) — 이미 가격에 반영

  • 연초 전에 시장이 이미 예상해 가격에 넣어 둔 부분
  • 예상대로 나와도 추가로 벌어 주는 것은 없다
  • 발표(announcement) = 예상된 부분 + 놀람(surprise)

U — 놀람

  • 예상하지 못한 모든 것. 가격을 움직이는 것은 이 부분뿐
  • 여러 기간 평균하면 0 — 부호를 예측할 수 있다면 이미 E(R)에 들어가 있을 것

강의 예: 시장은 A의 올해 수익률을 25%로 예상, 실제는 30% → U = 30% − 25% = +5%. 이 5%p만이 아무도 계획할 수 없었던 부분이다.

11.4Two types of risk — how many firms does a surprise reach?

Systematic riskUnsystematic risk
Other namesMarket risk, nondiversifiable riskUnique risk, asset-specific risk
ScopeNearly all assets, to varying degreesOne firm, at most a few
ExamplesInterest rates, inflation, GDP growth, tax law changesA strike at one plant, product failure, lawsuit, fire
In a large portfolioRemains — every holding is exposedCancels out — one firm's bad luck is offset by another's good luck

Total risk = systematic risk + unsystematic risk. The surprise U splits the same way: market-wide surprise + firm-specific surprise.

The test is not "how big is the event" or "was it expected" but how many firms it affects.

11.4위험의 두 종류 — 놀람이 몇 개 기업에 닿는가

체계적 위험 (systematic risk)비체계적 위험 (unsystematic risk)
다른 이름시장위험 (market risk), 분산 불가능 위험 (nondiversifiable)고유위험 (unique risk), 자산 특유 위험 (asset-specific)
영향 범위거의 모든 자산에, 정도 차이는 있지만한 기업, 많아야 소수 기업
예금리, 인플레이션, GDP 성장률, 세법 변경한 공장의 파업, 제품 실패, 소송, 화재
큰 포트폴리오에서남는다 — 모든 보유 종목이 노출상쇄된다 — 한 기업의 불운을 다른 기업의 행운이 메운다

총위험 (total risk) = 체계적 위험 + 비체계적 위험. 놀람 U도 같은 방식으로 나눌 수 있다: 시장 전체 놀람 + 기업 고유 놀람.

분류 기준은 "얼마나 큰 사건인가"나 "예상했는가"가 아니라 영향이 미치는 기업의 범위다.

  • The curve flattens near 20% = systematic risk (the floor)
  • Diversification removes unsystematic risk — at almost no cost
  • Diversification cannot remove systematic risk — every stock is exposed to rates, inflation, the economy

Systematic risk principle: no one is paid for risk that can be eliminated for free → the risk premium attaches only to systematic risk.

11.7Reward-to-risk ratio → CAPM

Reward-to-risk = (E(Ri) − Rf) / βi   — excess expected return per unit of systematic risk

Rf = 8%E(R)βRatio
Asset A22%1.6014% / 1.60 = 8.75%
Asset B13%1.205% / 1.20 = 4.17%

This cannot last: investors sell B and buy A → A's price↑, E(R)↓; B's price↓, E(R)↑ → until the two ratios are equal.

In equilibrium every asset has the same ratio. The market portfolio (β = 1) has ratio E(RM) − Rf, so:

E(Ri) = Rf + βi × [E(RM) − Rf]

β8% + β × 7%
0.08.0% (= Rf)
1.015.0% (= E(RM))
1.619.2%

균형에서는 모든 자산의 비율이 같다. 시장 포트폴리오(β = 1)의 비율은 E(RM) − Rf이므로:

E(Ri) = Rf + βi × [E(RM) − Rf]

11.7Security market line (SML) — above is undervalued, below is overvalued

OfferedSML requiredVerdict
A22%8% + 1.6 × 7% = 19.2%Undervalued (α +2.8%)
B13%8% + 1.2 × 7% = 16.4%Overvalued (α −3.4%)
  • α = offered E(R) − CAPM required return
  • Above (α > 0) = undervalued: buyers rush in, price↑, E(R)↓ → converges up to the line
  • Below (α < 0) = overvalued: sold off, price↓, E(R)↑
  • Intercept = Rf, slope = market risk premium 7%

11.7증권시장선 (SML) — 위는 저평가, 아래는 고평가

제시SML 요구판정
A22%8% + 1.6 × 7% = 19.2%저평가 (α +2.8%)

  • 아래 (α < 0) = 고평가 (overvalued): 팔려서 가격↓, E(R)↑
  • 절편 = Rf, 기울기 = 시장위험프리미엄 (market risk premium) 7%

11.8The required return is the discount rate (cost of capital)

In Ch.8–9 we discounted project cash flows at the "required return" without saying where that number comes from. It comes from the SML.

The rule

  • Project's expected return > return the market requires for its systematic risk → accept
  • = the project lies above the SML
  • Using the SML required return as the NPV discount rate, NPV > 0 ⇔ above the SML — the same test

The project's risk, not the firm's

  • If a stable utility starts a software business, discount at the software β
  • Using the firm's own low β makes almost every risky project look good
  • One firm-wide discount rate → accepts too many risky projects, rejects too many safe ones

11.8요구수익률이 곧 할인율 (cost of capital)

Ch.8–9에서 프로젝트 현금흐름을 "요구수익률"로 할인했지만 그 숫자의 출처는 말하지 않았다. 출처는 SML이다.

규칙

  • 프로젝트의 기대수익률 > 그 체계적 위험에 대해 시장이 요구하는 수익률 → 채택
  • = 프로젝트가 SML 위에 있다
  • SML 요구수익률을 NPV 할인율로 쓰면 NPV > 0 ⇔ SML 위 — 같은 검사

회사가 아니라 프로젝트의 위험

  • 안정적인 전력회사가 소프트웨어 사업을 시작하면 소프트웨어 β로 할인해야 한다
  • 회사 자신의 낮은 β를 쓰면 거의 모든 위험한 프로젝트가 좋아 보인다
  • 회사 전체 단일 할인율 → 위험한 프로젝트 과다 채택, 안전한 프로젝트 과소 채택

Problem 5Expected return of a portfolio given in dollars

You invest $4,500 in Stock A (expected return 10%), $7,500 in Stock B (16%), and $3,000 in Stock C (5%). What is the portfolio's expected return? Why does it differ from the simple average of the three returns?

Total = 4,500 + 7,500 + 3,000 = $15,000 → weight w = amount ÷ total

wA = 4,500 / 15,000 = 0.30 · wB = 7,500 / 15,000 = 0.50 · wC = 3,000 / 15,000 = 0.20

E(RP) = Σ w × E(R) = 0.30 × 10% + 0.50 × 16% + 0.20 × 5% = 3.0% + 8.0% + 1.0% = 12.0%

The simple average (10% + 16% + 5%) / 3 = 10.33% is the answer if equal amounts were put in each stock. Half the money is in B at 16%, so the portfolio return is higher.

Weights always use the amount invested — not the number of shares or stocks.

Problem 9Diversification — how much, and down to where?

Average σ of randomly chosen portfolios: 1 stock 52.0% · 4 stocks 30.5% · 10 stocks 24.0% · 25 stocks 21.4% · 60 stocks 20.6%. (a) By what % does risk fall from 1 → 10 stocks? (b) From 25 → 60 stocks? (c) What is the roughly 20% that remains at 60 stocks, and does it reach 0 with more stocks?

(a) (52.0 − 24.0) / 52.0 = 28.0 / 52.0 = 53.8% reduction — adding just the first 3 stocks (1 → 4) gives 21.5%p

(b) 21.4 − 20.6 = 0.8%p — buying 35 more stocks gains almost nothing

(c) The remainder is systematic risk — every stock is exposed to rates, inflation and the economy together, so averaging does not remove it. No matter how many stocks are added it never reaches 0 and converges to this floor.

The part that disappeared (52.0% → about 20%) is unsystematic risk — it can be removed almost for free, so the market pays nothing for bearing it.

문제 9분산투자 — 얼마나, 어디까지 줄어드나

Problem 10Must a stock with higher total risk earn more?

Rf = 3.5%, market risk premium = 6%. Stock P (a mining exploration firm) has σ = 60%, β = 0.4. Stock Q (an airline) has σ = 30%, β = 1.4. What is each CAPM required return? Which stock's risk is the "rewarded" risk?

E(Ri) = Rf + βi × MRP

P = 3.5% + 0.4 × 6% = 3.5% + 2.4% = 5.9%

Q = 3.5% + 1.4 × 6% = 3.5% + 8.4% = 11.9%

P's σ is double Q's, but Q's required return is more than double P's. P's risk is mostly unsystematic (firm-specific events such as exploration success or failure), which diversification removes for free → no reward.

Q's risk has a large systematic part that moves with the economy (β 1.4) → the reward attaches to β. High σ ≠ high β.

Problem 13Comparing reward-to-risk ratios

Rf = 5%. Asset C has expected return 17% and β = 1.5; Asset D has expected return 11% and β = 0.8. (a) What is each asset's reward-to-risk ratio? (b) How do investors act, and how do the two assets' prices and expected returns change?

(a) Reward-to-risk = (E(R) − Rf) / β

C = (17% − 5%) / 1.5 = 12% / 1.5 = 8.0% · D = (11% − 5%) / 0.8 = 6% / 0.8 = 7.5%

(b) C pays 8.0% per unit of systematic risk, D pays 7.5% → investors sell D and buy C

C's price↑ → C's expected return↓ · D's price↓ → D's expected return↑ — continuing until the two ratios are equal

We buy C not because its expected return is higher (the βs differ) but because it pays more per unit of β. In equilibrium every asset has the same ratio, and that value is the market risk premium.
