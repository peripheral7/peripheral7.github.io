11.1 기대수익률 (expected return) — 확률가중평균

Ch.10은 실제로 일어난 일을 평균했다. 11장은 일어날 수 있는 일을 각 상황(state)의 확률로 가중해 평균한다.

E(R) = p1R1 + p2R2 + … + pnRn   (Σp = 1)

StateChanceStock AStock B
Recession0.50−20%+30%
Boom0.50+70%+10%
E(R)25%20%

E(RA) = 0.50 × (−20%) + 0.50 × 70% = −10% + 35% = 25%

E(RB) = 0.50 × 30% + 0.50 × 10% = 15% + 5% = 20%

A의 기대수익률이 더 높지만 그래서 "더 좋은 주식"인 것은 아니다 — 위험(σ)을 봐야 한다.

빠진 확률이 있으면 먼저 1 − (나머지 확률의 합)으로 채운다.

11.1 분산 (variance) · 표준편차 (standard deviation)

σ² = p1(R1 − E(R))² + … + pn(Rn − E(R))²   ·   σ = √σ²

StateA: p(R − 25%)²B: p(R − 20%)²
Recession0.50 × (−0.45)² = 0.101250.50 × 0.10² = 0.005
Boom0.50 × 0.45² = 0.101250.50 × (−0.10)² = 0.005
Variance0.20250.0100
σ√0.2025 = 45%√0.0100 = 10%
  • 분산 = 기대수익률에서 벗어난 정도(편차²)의 확률가중평균
  • 소수(decimal)로 계산하고 마지막에 √ — 소수 넷째 자리 이상 유지
  • A: 25%, σ 45% · B: 20%, σ 10% → A는 수익도 위험도 크다

BA II Plus: 2nd DATA에 X = 수익률(%), Y = 확률 × 100 → 2nd STAT에서 x̄ = E(R), σx = σ (Sx 아님). 강의 연습(C·D, p.9): E(R) 12.60% · 8.25%, σ 20.01% · 6.94%

11.2 포트폴리오 기대수익률 — 두 경로, 같은 답

E(RP) = w1E(R1) + w2E(R2) + …   (w = 투자금 비중, Σw = 1)

경로 1 — 기대수익률을 평균

A 50% · B 50%

E(RP) = 0.50 × 25% + 0.50 × 20% = 12.5% + 10% = 22.5%

경로 2 — 상황별 포트폴리오 수익률

StatepRP
Recession0.500.5(−20%) + 0.5(30%) = +5%
Boom0.500.5(70%) + 0.5(10%) = +40%
Expected0.5(5%) + 0.5(40%) = 22.5%

기대수익률은 가중평균이므로 "먼저 평균 → 결합"이든 "먼저 결합 → 평균"이든 항상 같다.

11.2 포트폴리오 위험은 가중평균이 아니다

σA = 45%, σB = 10%. 반반 포트폴리오의 σ는 27.5%가 아니다 — 포트폴리오 자체의 상황별 수익률로 계산한다.

StatepRPp × (RP − 22.5%)²
Recession0.50+5%0.50 × (−0.175)² = 0.0153125
Boom0.50+40%0.50 × 0.175² = 0.0153125
Variance0.030625

가중평균이라면: 0.50 × 45% + 0.50 × 10% = 27.5%

실제: σP = √0.030625 = 17.5%

왜 작은가? 불황에 A↓ B↑ — 반대로 움직여 서로 상쇄한다. 이것이 분산투자(diversification)의 씨앗이다.

11.3 발표와 놀람 — R = E(R) + U

실제 수익률 R = 기대수익률 E(R) + 예상치 못한 수익률 U

E(R) — 이미 가격에 반영

  • 연초 전에 시장이 이미 예상해 가격에 넣어 둔 부분
  • 예상대로 나와도 추가로 벌어 주는 것은 없다
  • 발표(announcement) = 예상된 부분 + 놀람(surprise)

U — 놀람

  • 예상하지 못한 모든 것. 가격을 움직이는 것은 이 부분뿐
  • 여러 기간 평균하면 0 — 부호를 예측할 수 있다면 이미 E(R)에 들어가 있을 것

강의 예: 시장은 A의 올해 수익률을 25%로 예상, 실제는 30% → U = 30% − 25% = +5%. 이 5%p만이 아무도 계획할 수 없었던 부분이다.

11.4 위험의 두 종류 — 놀람이 몇 개 기업에 닿는가

체계적 위험 (systematic risk)비체계적 위험 (unsystematic risk)
다른 이름시장위험 (market risk), 분산 불가능 위험 (nondiversifiable)고유위험 (unique risk), 자산 특유 위험 (asset-specific)
영향 범위거의 모든 자산에, 정도 차이는 있지만한 기업, 많아야 소수 기업
예금리, 인플레이션, GDP 성장률, 세법 변경한 공장의 파업, 제품 실패, 소송, 화재
큰 포트폴리오에서남는다 — 모든 보유 종목이 노출상쇄된다 — 한 기업의 불운을 다른 기업의 행운이 메운다

총위험 (total risk) = 체계적 위험 + 비체계적 위험. 놀람 U도 같은 방식으로 나눌 수 있다: 시장 전체 놀람 + 기업 고유 놀람.

분류 기준은 "얼마나 큰 사건인가"나 "예상했는가"가 아니라 영향이 미치는 기업의 범위다.

  • 효과는 초반에 몰린다 — 처음 몇 종목이 위험의 절반 이상을 없앤다
  • 곡선은 약 20% 근처에서 평평해진다 = 체계적 위험 (바닥)
  • 분산투자는 비체계적 위험을 없앤다 — 비용은 거의 0
  • 분산투자는 체계적 위험을 없앨 수 없다 — 모든 종목이 금리·인플레·경기에 노출

체계적 위험 원칙 (systematic risk principle): 공짜로 없앨 수 있는 위험에는 아무도 보상하지 않는다 → 위험 프리미엄은 체계적 위험에만 붙는다.

11.6 베타 (β) — 시장 움직임을 얼마나 따라가나

σ = 총위험. β = 시장과 함께 움직이는 부분, 즉 분산투자 뒤에도 남는 체계적 위험만.

β의미예
β = 1시장과 1 대 1시장지수 1.0
β > 1시장 움직임을 증폭항공·명품·기술 ≈ 1.5
0 < β < 1완화전력·필수식품 ≈ 0.5
β = 0시장과 무관무위험자산

σ가 커도 β는 작을 수 있다 — 금광회사는 변동이 크지만 시장을 거의 따라가지 않는다.

포트폴리오 β — 여기서는 가중평균이 맞다

βP = w1β1 + w2β2 + …

11.7 보상 대 위험 비율 (reward-to-risk ratio) → CAPM

Reward-to-risk = (E(Ri) − Rf) / βi   — 체계적 위험 1단위당 초과 기대수익률

Rf = 8%E(R)β비율
Asset A22%1.6014% / 1.60 = 8.75%
Asset B13%1.205% / 1.20 = 4.17%

오래갈 수 없다: 투자자는 B를 팔고 A를 산다 → A 가격↑·E(R)↓, B 가격↓·E(R)↑ → 두 비율이 같아질 때까지.

균형에서는 모든 자산의 비율이 같다. 시장 포트폴리오(β = 1)의 비율은 E(RM) − Rf이므로:

E(Ri) = Rf + βi × [E(RM) − Rf]

11.7 증권시장선 (SML) — 위는 저평가, 아래는 고평가

제시SML 요구판정
A22%8% + 1.6 × 7% = 19.2%저평가 (α +2.8%)
B13%8% + 1.2 × 7% = 16.4%고평가 (α −3.4%)
  • α = 제시 E(R) − CAPM 요구수익률
  • 위 (α > 0) = 저평가 (undervalued): 사려는 사람이 몰려 가격↑, E(R)↓ → 선 위로 수렴
  • 아래 (α < 0) = 고평가 (overvalued): 팔려서 가격↓, E(R)↑
  • 절편 = Rf, 기울기 = 시장위험프리미엄 (market risk premium) 7%

11.7 CAPM 항목과 포트폴리오 예

항목의미강의 예
Rf체계적 위험이 없을 때의 수익률 (SML 절편)8%
E(RM) − Rf시장위험프리미엄 — SML의 기울기7% (E(RM) = 15%)
βi그 위험을 이 자산이 얼마나 지고 있나자산마다 다름

예: β = 1.60 주식 40%, β = 0.80 주식 60%

βP = 0.40 × 1.60 + 0.60 × 0.80 = 0.64 + 0.48 = 1.12

E(RP) = 8% + 1.12 × 7% = 8% + 7.84% = 15.84%

검산: 각 주식의 CAPM 수익률 19.2%, 13.6%의 가중평균 = 0.40 × 19.2% + 0.60 × 13.6% = 7.68% + 8.16% = 15.84% — 같은 값 (SML이 직선이기 때문).

11.8 요구수익률이 곧 할인율 (cost of capital)

Ch.8–9에서 프로젝트 현금흐름을 "요구수익률"로 할인했지만 그 숫자의 출처는 말하지 않았다. 출처는 SML이다.

규칙

  • 프로젝트의 기대수익률 > 그 체계적 위험에 대해 시장이 요구하는 수익률 → 채택
  • = 프로젝트가 SML 위에 있다
  • SML 요구수익률을 NPV 할인율로 쓰면 NPV > 0 ⇔ SML 위 — 같은 검사

회사가 아니라 프로젝트의 위험

  • 안정적인 전력회사가 소프트웨어 사업을 시작하면 소프트웨어 β로 할인해야 한다
  • 회사 자신의 낮은 β를 쓰면 거의 모든 위험한 프로젝트가 좋아 보인다
  • 회사 전체 단일 할인율 → 위험한 프로젝트 과다 채택, 안전한 프로젝트 과소 채택

10.05% < 13.58% — Y는 불황에 오르고 X는 떨어져 서로 상쇄한다.

σ를 가중평균하는 것은 대표적인 함정이다. σP는 항상 포트폴리오 자체의 상황별 수익률로 계산한다.

문제 5 · 금액으로 주어진 포트폴리오의 기대수익률

Stock A에 $4,500 (기대수익률 10%), Stock B에 $7,500 (16%), Stock C에 $3,000 (5%)를 투자했다. 포트폴리오의 기대수익률은? 세 수익률의 단순평균과 왜 다른가?

총액 = 4,500 + 7,500 + 3,000 = $15,000 → 비중 w = 금액 ÷ 총액

wA = 4,500 / 15,000 = 0.30 · wB = 7,500 / 15,000 = 0.50 · wC = 3,000 / 15,000 = 0.20

E(RP) = Σ w × E(R) = 0.30 × 10% + 0.50 × 16% + 0.20 × 5% = 3.0% + 8.0% + 1.0% = 12.0%

단순평균 (10% + 16% + 5%) / 3 = 10.33%는 세 주식에 같은 금액을 넣었을 때의 답이다. 돈의 절반이 16%짜리 B에 있으므로 포트폴리오 수익률이 더 높다.

비중은 항상 투자금 기준 — 주식 수나 종목 수가 아니다.

문제 6 · 위험을 완전히 없애는 비중

두 상황(확률 각 0.50)에서 Stock K는 불황 −10%, 호황 +30%, Stock L은 불황 +20%, 호황 0%를 번다. (a) 각 주식의 E(R)는? (b) K의 비중 w를 얼마로 하면 포트폴리오 수익률이 두 상황에서 같아지는가? 그때 E(RP)와 σP는?

(a) E(RK) = 0.50 × (−10%) + 0.50 × 30% = 10% · E(RL) = 0.50 × 20% + 0.50 × 0% = 10%

(b) 불황 = 호황: w(−10%) + (1 − w)(20%) = w(30%) + (1 − w)(0%)

20% − 30%w = 30%w → 60%w = 20% → w = 1/3 (K 1/3, L 2/3)

불황: (1/3)(−10%) + (2/3)(20%) = 10% · 호황: (1/3)(30%) + (2/3)(0%) = 10%

E(RP) = 10%, 두 상황 모두 10%이므로 σP = 0 — 각 주식의 σ는 20%, 10%인데도.

완전히 반대로 움직이는 두 자산이라 가능한 극단적인 경우. 현실에서는 0까지는 못 가지만 같은 원리로 위험이 줄어든다.

문제 7 · 실제 수익률을 기대 + 놀람으로 나누기

문제 9 · 분산투자 — 얼마나, 어디까지 줄어드나

(a) (52.0 − 24.0) / 52.0 = 28.0 / 52.0 = 53.8% 감소 — 처음 3종목 추가(1 → 4)만으로도 21.5%p

(b) 21.4 − 20.6 = 0.8%p — 35종목을 더 사서 얻는 것이 거의 없다

(c) 남는 부분은 체계적 위험 — 모든 종목이 금리·인플레·경기에 함께 노출되므로 평균해도 사라지지 않는다. 종목을 아무리 늘려도 0이 되지 않고 이 바닥에 수렴한다.

사라진 부분 (52.0% → 약 20%)이 비체계적 위험 — 거의 공짜로 없앨 수 있으므로 시장은 이것을 지는 대가를 주지 않는다.

문제 10 · 총위험이 큰 주식이 더 많이 벌어야 하나?

Rf = 3.5%, 시장위험프리미엄 = 6%. Stock P(광산 탐사회사)는 σ = 60%, β = 0.4. Stock Q(항공사)는 σ = 30%, β = 1.4. CAPM 요구수익률은 각각? 어느 주식의 위험이 "보상받는" 위험인가?

E(Ri) = Rf + βi × MRP

P = 3.5% + 0.4 × 6% = 3.5% + 2.4% = 5.9%

Q = 3.5% + 1.4 × 6% = 3.5% + 8.4% = 11.9%

σ는 P가 두 배지만 요구수익률은 Q가 두 배 이상이다. P의 위험은 대부분 비체계적(탐사 성공·실패 같은 기업 고유 사건)이라 분산투자로 공짜로 없어진다 → 보상 없음.

Q의 위험은 경기에 따라 움직이는 체계적 부분이 크다(β 1.4) → 보상은 β에 붙는다. 높은 σ ≠ 높은 β.

문제 13 · 보상 대 위험 비율 비교

(b) C는 체계적 위험 1단위당 8.0%, D는 7.5%를 준다 → 투자자는 D를 팔고 C를 산다

C 가격↑ → C의 기대수익률↓ · D 가격↓ → D의 기대수익률↑ — 두 비율이 같아질 때까지 계속된다

기대수익률이 높아서가 아니라(β가 다르므로) β 1단위당 보상이 높아서 C를 산다. 균형에서는 모든 자산의 비율이 같고, 그 값이 시장위험프리미엄이다.

문제 15 · SML 선상의 두 자산으로 Rf와 MRP 역산

문제 18 · 가격에서 기대수익률을 구해 SML과 비교

(c) 11.2%를 벌 수 있는 가격: P0 = (D1 + P1) / (1 + 0.112) = 56 / 1.112 = $50.36

매수세가 가격을 $50 → $50.36으로 올리면 기대수익률이 12.0% → 11.2%로 내려가 SML 위에 놓인다 — "위 = 저평가 → 가격 상승 → 선으로 수렴"을 숫자로 본 것.

문제 19 · 회사 β가 아니라 프로젝트 β로 할인

r = 8.2%: −1,000,000 + 400,000 × 2.56783 = +$27,130.02  ·  r = 12.4%: −1,000,000 + 400,000 × 2.38542 = −$45,832.84
