12.2 자기자본비용(cost of equity) — 두 가지 방법

이 장의 회사: 주가 $40, 내년 배당 D1 $2.20, 성장률 6% · β 1.20, Rf 4%, 시장위험프리미엄 7%

배당성장모형 (dividend growth model)

RE = D1 / P0 + g

2.20 / 40 + 6% = 5.50% + 6% = 11.50%

약점: g 에 매우 민감, 무배당 기업엔 못 쓴다

증권시장선 (SML)

RE = Rf + βE[E(RM) − Rf]

4% + 1.20 × 7% = 4% + 8.40% = 12.40%

장점: 무배당 기업에도, 위험을 명시적으로 → 프로젝트에도 쓸 수 있다

같은 회사, 같은 날인데 거의 1%p 차이 — 정상이다. 둘 다 구해 판단하고, 프로젝트에는 SML. 둘 다 과거를 연장한 추정치(backward-looking).

12.3 부채비용(cost of debt)과 우선주

쿠폰이 아니라 오늘의 YTM

쿠폰 9%, 반기 지급, 만기 20년가격 $1,099
N = 40, PV = −1,099, PMT = 45, FV = 1,000I/Y = 4.00%
RD = YTM4.00% × 2 = 8.00%

액면보다 비싸게 팔린다 = 시장은 9%보다 덜 요구한다. 9%는 과거의 사실.

부채는 세후로 (이자는 비용공제)

RD(1 − TC) = 8% × 0.79 = 6.32%

이자 $1,000,000 → 절세 $210,000 → 순비용 $790,000 (79%)

우선주 (preferred stock) — 성장 없는 영구연금

RP = D / P0 = 3.00 / 40 = 7.50%

배당은 세후 이익에서 나가므로 RE·RP에는 (1 − TC)가 없다 — 이 비대칭이 Ch.13 자본구조 논의의 출발점.

  • 가중치는 시장가치 — 장부가치(book value)는 회계용. 가장 크게 어긋나는 건 자기자본

Pure play approach — 물류 사업 진출

물류 상장사 β: 0.70, 0.85, 0.79평균 0.78

Subjective approach — 위험등급별 가감

등급조정할인율

12.6 WACC로 회사 전체 가치 평가

회사 = 프로젝트의 묶음 → 회사의 잉여현금흐름(free cash flow)을 회사의 WACC로 할인. 위험이 정의상 회사 자신의 것이라 WACC가 맞는 할인율.

V0 = FCF1 / (WACC − g)

자기자본 $60.43M ≈ 처음 주어진 시장가치 $60M — 장 전체 숫자가 서로 맞물린다.

12.7 발행비용(flotation costs)

새 증권을 발행하면 인수 수수료 등으로 조달액 일부가 사라진다 → 필요한 금액보다 더 많이 조달해야 한다.

fA = (E/V)·fE + (D/V)·fD   조달액 = 필요액 / (1 − fA)

가중치 E/V 0.60, D/V 0.40 · 가정 fE 10%, fD 5%fA = 6% + 2% = 8%
필요액 $10M10 / 0.92 = $10.87M 조달
발행비용$0.87M → 초기 투자비에 더한다

강의 PDF(28장)에는 12.7 슬라이드가 없어 fE·fD는 설명용 가정 수치. 발행비용은 할인율이 아니라 현금흐름(초기 비용)에서 처리한다 — 수업에서 확인.

수업 전에 스스로 확인할 질문

  1. 채권 가격이 $1,099(쿠폰 9%)인데 왜 부채비용은 9%가 아니라 8%인가? → 할증 거래 = 시장 요구수익률(YTM) 8% < 쿠폰. 지금 조달하는 비용은 YTM.
  2. 왜 RD에만 (1 − TC)를 곱하나? → 이자는 비용공제, 배당은 세후 이익에서 지급.
  3. 배당 $1.60을 “방금 지급”했고 g = 4%, 주가 $35면 RE는? → D1 = 1.664, 1.664/35 + 4% = 8.75% (1.60 그대로면 8.57% — 오답).
  4. 가중치에 장부가치를 쓰면 안 되는 이유는? → 투자자는 오늘의 가치를 본다. 장부 자기자본은 시장가와 크게 어긋난다.
  5. WACC 9.97% 회사가 β 0.6, 수익률 9.0% 프로젝트를 WACC로 평가하면? → 기각. 하지만 SML 요구 8.2% < 9.0% 이므로 채택이 옳다.
  6. FCF1 $7.0M, g 3%, WACC 9.97%, 부채 $40M일 때 자기자본 가치는? → 7.0/0.0697 = $100.43M − $40M = $60.43M.

→ 키로 답이 하나씩 나타난다.
